## What is in this repo
| Folder | What goes there |
|---|---|
| docs/ | proposal, weekly logbook, report chapters, decision log |
| hardware/ | design notes per block, schematics, PCB files, bill of materials |
| firmware/ | STM32 code and the serial data format |
| host/ | laptop script that reads the STM32 and does the demodulation |
| eidors/ | MATLAB/Octave scripts that turn readings into images |
| analysis/ | scripts that compute SNR, position error, size error, fault results |
| tests/ | the written protocol for each experiment |
| data/ | raw and processed measurements |
| figures/ | plots and photos used in the report |
